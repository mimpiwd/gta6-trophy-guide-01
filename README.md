An offline GTA 6 trophy guide and tracker for PlayStation 5: all 55 official trophies with guides in our own words and cited sources, a roadmap to the platinum, missable flags, filters by kind and grade, a spoiler-safe mode, and a checklist that saves in your browser (with export and import). No network needed — serve `app/` and open it.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
